2026, ongoing

Warden

A runtime policy layer for sandboxed AI agents. It mediates every outbound network request, validates the artifacts an agent writes before anything downstream runs them, and gives the agent a short-lived, narrowly scoped identity. Built on gVisor and Firecracker, with Terraform for the infrastructure around it.

So far: across 25 trials per condition, egress mediation cut the unauthorized-egress rate by 74% versus gVisor's default isolation alone. Next is an adversarial control evaluation against an agent that is explicitly trying to get out.
